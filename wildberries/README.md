# Кубики · аналитика продавца Wildberries

**Задача.** Продавцу нужно было понимать, какие товары приносят маржу, где её съедает реклама и когда пора пополнить остатки.

**Результат.** Разработал систему в Google Таблицах с дневными и недельными отчётами по артикулам и моделям. Она объединяет заказы, воронку, рекламу и остатки, рассчитывает маржу с учётом выкупа и расходов и позволяет проверить экономику новинки.

**Архитектура.** API Wildberries → загрузка на Google Apps Script → технические листы и справочники → расчёты по артикулу и дате → отчёты «Кубики» и «Кубики модели».

## Демо

- **Дашборд.** После распаковки репозитория откройте `docs/wildberries/index.html` в браузере. В демо есть диагностика артикулов, сценарии цены и рекламы, остатки и калькулятор новинки.
- [Excel-книга](wildberries-synthetic.xlsx) — структура системы, формулы и лист «Обзор».

Демонстрации подготовлены для портфолио на синтетических данных.
