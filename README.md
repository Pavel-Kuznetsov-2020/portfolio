# Павел Кузнецов · портфолио BI и аналитики данных

Разрабатываю системы отчётности для бизнеса. Подключаю данные, проектирую расчёты и собираю отчёты, по которым можно принимать решения.

| Проект | Что посмотреть |
| --- | --- |
| [Wildberries](wildberries/README.md) | Маржа по артикулам, реклама, остатки и калькулятор новинки |
| [Бурение скважин и монтаж](drilling/README.md) | Реестр заявок, частичные оплаты, ДДС и ОПиУ |
| [Маркетинговые проекты](marketing-analytics/README.md) | План и факт встреч, затраты, прибыль и назначение менеджеров |
| [Розничная сеть](meat-retail/README.md) | Остатки и списания по точкам, перемещение товара, денежные операции |
| [Experimental Data Processing](experimental-data-processing/README.md) | Лабораторные работы и итоговый проект по анализу экспериментальных данных |

**Как запустить демо.** На GitHub выберите **Code → Download ZIP**, распакуйте архив и откройте `docs/index.html` в браузере. На странице доступны четыре интерактивных кейса. Excel-книги лежат в папках проектов.
