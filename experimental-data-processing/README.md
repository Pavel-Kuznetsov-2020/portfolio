# Experimental Data Processing · Сколтех

Учебные работы по регрессии, сглаживанию и оценке траекторий по шумным данным. В итоговом проекте по измерениям дальности и азимута оценивали точки старта трёх целей и проверяли, какие цели могли стартовать из одного места.

**Вклад.** Каждое задание выполнял самостоятельно. В групповые отчёты входили выбранные командой решения. Портфолио содержит Python-версии экспериментов и основные учебные ноутбуки.

## Запуск на macOS

Из папки `experimental-data-processing` в терминале с Python 3.10 или новее:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python run.py final-project
python run.py lab-09
```

Результаты сохраняются в `results/<название>`. Для быстрого прогона всего курса используйте `python run.py all --trials 12`. Для 500 прогонов работы № 5 используйте `python run.py lab-05 --trials 500`. Фиксированное значение `--seed` позволяет повторить результаты.

## Источники и воспроизводимость

- Работы № 5, 8, 9, 11 и итоговый проект содержали C++. В портфолио соответствующие эксперименты реализованы на Python. В № 5 сохранены сценарии и 18 графиков исходной программы.
- В отчёте № 12 описание двух датчиков сопровождается листингом из задания про пропуски. Слияние датчиков восстановлено по описанию, а сценарий с пропусками доступен в № 9.
- Папки № 1–7 содержат `course-notes.ipynb` с исходным Python-кодом для просмотра. Выводы ячеек очищены. Некоторые из этих ноутбуков ссылаются на файлы из учебного архива. Для запуска без исходных файлов используйте общий `run.py`.
- Демо запускается на моделируемых данных. Числа на графиках относятся к этим прогонам. Исходные радарные файлы можно передать отдельно, если они есть.
