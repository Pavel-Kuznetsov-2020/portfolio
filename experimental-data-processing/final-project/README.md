# Восстановление точек старта по радарным измерениям

**Задача.** По ряду зашумлённых измерений дальности и азимута оценить, откуда начали движение три цели и могли ли они стартовать из одного места.

**Метод.** Расширенный фильтр Калмана оценивает положение и скорость. Обратное сглаживание RTS уточняет начало траектории по всей истории измерений. Эллипсы показывают неопределённость стартовых координат. Таблица сравнения использует расстояние Махаланобиса и предполагает независимость ошибок разных траекторий.

[График одного прогона](radar-origins.png) показывает синтетический сценарий, где две цели стартуют из одной точки, а третья из другой.

Из папки `experimental-data-processing`:

```bash
python run.py final-project
```

Результаты в `results/final-project/`. Для своих файлов используйте `python run.py final-project --data-dir /путь/к/данным`. Ожидаются `z1.txt`, `z2.txt` и `z3.txt` с двумя столбцами через пробел: дальность в метрах и азимут в радианах по часовой стрелке от севера. Интервал между измерениями — 1 секунда.
