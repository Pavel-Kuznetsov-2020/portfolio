# Сглаживание ряда и поверхности

Сравнение 13-месячного среднего и двустороннего EMA. Для поверхности сглаживание применяется по строкам и столбцам.

Из папки `experimental-data-processing` запустите `python run.py lab-04`. В `results/lab-04/` появятся графики (monthly-smoothing.png и surface-smoothing.png) и таблица ошибок.
