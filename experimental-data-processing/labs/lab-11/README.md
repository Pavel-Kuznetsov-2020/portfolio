# EKF для спасательного катера

Оценка траектории по дальности и азимуту. Ошибки прогноза и обновления считаются отдельно для каждого канала.

Из папки `experimental-data-processing` запустите `python run.py lab-11`. В `results/lab-11/` появятся графики (radar-errors.png, radar-measurements.png и radar-track.png) и таблица ошибок.
