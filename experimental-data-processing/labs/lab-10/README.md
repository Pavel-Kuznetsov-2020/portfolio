# Преобразование радарных измерений

Отслеживание ближней и дальней цели при двух настройках шума. Якобиан переносит ковариацию из полярных координат в декартовы.

Из папки `experimental-data-processing` запустите `python run.py lab-10`. В `results/lab-10/` появятся графики (converted-radar.png) и таблица ошибок.
