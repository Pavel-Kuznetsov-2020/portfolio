# Отслеживание при пропусках GNSS

Сравнение оценок на текущем шаге и прогноза на шесть шагов. Пунктир показывает расчётную неопределённость, сплошные линии — эмпирическую ошибку.

Из папки `experimental-data-processing` запустите `python run.py lab-09`. В `results/lab-09/` появятся графики (gnss-dropouts.png) и таблица ошибок.
