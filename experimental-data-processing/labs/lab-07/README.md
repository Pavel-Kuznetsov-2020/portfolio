# Движение с коррелированным шумом

Сравнение модели белого шума и модели AR(1) при коррелированных ускорении, ошибках измерения и их сочетании.

Из папки `experimental-data-processing` запустите `python run.py lab-07`. В `results/lab-07/` появятся графики (correlated-noise.png) и таблица ошибок.
