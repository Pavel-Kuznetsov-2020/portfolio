# Линейный фильтр Калмана для траектории плота

Python-порт учебной программы `FK.cpp`. Сравнивает измерения, фильтрацию и прогноз в сценариях с различным шумом и настройками фильтра. [Пример графиков](experiment.png).

Запуск из корня проекта: `python run.py lab-05 --trials 500`. Скрипт сохраняет 18 графиков в `results/lab-05/`.
